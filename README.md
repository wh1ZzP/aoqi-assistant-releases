# 终焉神奥奇助手

本仓库提供 Windows、Mac 客户端成品及云更新清单。

[下载最新版](https://github.com/wh1ZzP/aoqi-assistant-releases/releases/latest)

## 软件内更新

0.8.3 及以后版本在启动时自动检查新版。点击“立即更新”，由助手下载、退出、替换并重新打开，账号和录制保留。

已有 0.8.0–0.8.2 用户只需启用一次：

- Windows：完整退出助手，运行 [启用工具](https://github.com/wh1ZzP/aoqi-assistant-releases/releases/latest/download/aoqi-enable-updates-windows.cmd)，再打开原来的 EXE。
- Mac：完整退出助手，解压 [启用工具](https://github.com/wh1ZzP/aoqi-assistant-releases/releases/latest/download/aoqi-enable-updates-macos.zip)，运行 enable-update-source.command，选择原来的助手应用。

启用工具只写入更新源配置，不删除程序，不修改账号、阵型或录制。0.7.x 尚无内置更新器，需要先使用一次支持更新的版本。

更新清单固定为 [update.json](https://github.com/wh1ZzP/aoqi-assistant-releases/releases/latest/download/update.json)。网络需能访问 GitHub；检查或下载失败时可以继续使用旧版。

本仓库仅发布成品与更新资料，不包含开发源码仓库。
